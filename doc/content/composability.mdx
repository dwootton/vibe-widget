A widget can be written to a single portable file, and generated code is also kept in your project
so that a later call reuses it. Both let you come back to a widget without paying for another model
call.

## Save a widget

<WidgetPreview src="/widgets/scatter_brush.js" height={380} />

```python
widget = vw.create("scatter plot with brush selection", df)
widget.save("my_widget.vw")
```

To store the input values alongside the code, so the widget reloads showing the same state:

```python
widget.save("my_widget_with_inputs.vw", include_inputs=True)
```

A `.vw` bundle holds the widget code, its metadata, and the signatures of its inputs and outputs.
With `include_inputs=True` the input values are embedded as well.

## Load a widget

```python
loaded = vw.load("my_widget.vw")
loaded
```

Loading uses approval mode by default, so you can read the code before it runs:

```python
loaded = vw.load("my_widget.vw", approval=True)
```

For a file you trust and want to run straight away:

```python
loaded = vw.load("my_widget.vw", approval=False)
```

Calling `vw.load()` with no path opens a selector listing the widgets cached in your project.

## Sharing through git

Generated code is stored under `.vibewidget/` in your project, as one `.js` file and one `.json`
sidecar per widget. Commit `.vibewidget/widgets/` and a collaborator who clones the repository gets
your widgets with it. Opening one of them makes no model call, so a collaborator needs no API key
until they generate, edit, or audit something themselves.

Audit reports are written to `.vibewidget/audits/`, which is listed in `.vibewidget/.gitignore`, so
reports stay on the machine that produced them.

## Clearing what is stored

`vw.clear()` deletes cached widgets and audit reports, forgets the themes generated this session,
and returns a count of what it removed.

```python
vw.clear()            # everything
vw.clear("widgets")   # generated widget code only
vw.clear("audits")    # audit reports only
vw.clear("themes")    # forget themes generated this session
vw.clear(widget)      # just that widget's code and audits
vw.clear("sales_chart")  # the same, by variable name
```

Themes you saved with `Theme.save` are files in `.vibewidget/themes/` and are not removed by
`vw.clear`. Delete the file when you want one gone for good.

## Before you run a file someone sent you

A loaded widget executes JavaScript in your notebook with the privileges of the notebook page. Keep
`approval=True` for any file you did not generate yourself, and read the code before approving it.
