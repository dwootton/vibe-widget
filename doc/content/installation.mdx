Get up and running with Vibe Widget in seconds.

<InstallCommand command="pip install vibe-widget" />

Vibe Widget requires Python 3.9 or newer and one API key.

## 1. Add a key

Create a `.env` file next to your notebook with **any one** of these lines:

```bash
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-...
OPENROUTER_API_KEY=sk-or-...
```

Vibe Widget finds the `.env` file, picks the matching provider, and chooses a default model for it.
There is nothing else to configure. Exporting the same variable in your shell works too, and an
exported value always wins over the file.

Get a key from [Anthropic](https://console.anthropic.com/),
[OpenAI](https://platform.openai.com/) or [OpenRouter](https://openrouter.ai/). OpenRouter reaches
models from every vendor through one key.

## 2. Create a widget

<WidgetPreview src="/widgets/bar_chart_revenue.js" height={380} />

```python
import pandas as pd
import vibe_widget as vw

df = pd.read_csv("sales.csv")
widget = vw.create("bar chart of revenue by region", df)
widget
```

Check what was picked up at any time:

```python
vw.config()
# Config(provider='anthropic', host='api.anthropic.com', model='claude-opus-5',
#        key_source='ANTHROPIC_API_KEY (/work/analysis/.env)', environment='vscode-like', ...)
```

The repr never shows the key itself, only where it came from.

## Where it runs

The same two steps work in every supported host.

- **JupyterLab and Jupyter Notebook** — nothing extra.
- **VS Code notebooks** — React is bundled into each widget, because VS Code has no import maps.
- **Positron** — treated exactly like VS Code, and detected through `POSITRON` rather than `VSCODE_PID`.
- **Google Colab** — generation runs synchronously, since background threads break widget updates there.
- **Quarto** — works in `.qmd` documents rendered with the Jupyter engine; put the `.env` in the project directory.

## Brush selection example

<WidgetPreview src="/widgets/scatter_brush_linked.js" height={340} />

```python
import pandas as pd
import vibe_widget as vw

df = pd.read_csv("sales.csv")

widget = vw.create(
    "scatter plot with brush selection, and a linked histogram",
    df,
    outputs=vw.outputs(selected_indices="indices of selected points")
)

widget
```
