A theme is a description of how a widget should look, written in plain language, and the model
follows it while it generates the code. Themes are not stylesheets, so nothing is applied after the
fact.

## Listing the built-in themes

```python
import vibe_widget as vw

vw.themes()
```

In a notebook `vw.themes()` prints a short list. To get the underlying dict, use `dict(vw.themes())`.

## Using a theme

Pass the name of a built-in theme:

```python
vw.create("...", df, theme="financial_times")
```

A string that is not a registered theme name is treated as a description and sent to the model,
which writes a fresh theme for it. Doing so costs an extra model call and the result varies between
runs, so use a registered name when you want the same look every time. `vw.themes()` lists the names
that resolve without a model call, and a built-in name works even with no API key set.

## Writing your own theme

```python
theme = vw.theme("like national geographic but greener")

print(theme.description)

vw.create("...", df, theme=theme)
```

Pass the `Theme` object itself rather than `theme.description`. A description string is not a
registered name, so passing it sends you back through generation and produces a different theme.

To reuse a theme in later sessions, give it a name:

```python
theme.save("nat_geo_green")

vw.create("...", df, theme="nat_geo_green")
```

`Theme.save` writes a JSON file named after the theme into `.vibewidget/themes/` in your project and
registers the name for the rest of the session. Because the file sits in the project, it can be
committed and shared with the repository. Themes saved by older versions under
`~/.vibewidgets/themes/` are still read.

## Keeping a look across edits

An edit reuses the theme of the widget it came from, so the visual language stays the same while you
change behavior or layout.

<WidgetPreview src="/widgets/scatter_themed_ft.js" height={380} />

```python
v1 = vw.create("basic scatter", df, theme="financial_times")
```

<WidgetPreview src="/widgets/scatter_tooltips_legend.js" height={420} />

```python
v2 = v1.edit("add hover tooltips and a right-side legend")
```

To change the look on an edit, name a different theme:

```python
v3 = v2.edit("soften the palette and reduce gridlines", theme="minimal")
```
